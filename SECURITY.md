# Security and safety

Screen Sound Separation is an early, wildly undertested alpha. Do not use it for
safety-critical, production, broadcast, accessibility-dependent, or otherwise
important audio. It changes per-session Windows channel balance and relies on
best-effort cleanup when it stops.

For ordinary bugs, use the GitHub issue tracker. For a vulnerability that would
put users at risk if disclosed immediately, use GitHub's private vulnerability
reporting for this repository if it is available. Do not include credentials,
private browsing information, or unreviewed logs in a public report.

No release is currently guaranteed to receive security updates. The latest code
on `main` is the only version maintainers should assume is supported.
