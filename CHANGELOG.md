# Changelog

All notable changes to Screen Sound Separation will be recorded here. The
project is currently an early alpha and does not promise API or configuration
stability.

## [Unreleased]

- Open-sourced the project under the MIT License.
- Added Windows continuous integration and explicit alpha safety guidance.

## [0.3.0] - 2026-10-17

- Redesigned the desktop app as a compact two-pane routing workspace.
- Added search, source filters, intensity presets, direct source positioning,
  manual refresh, keyboard shortcuts, and a visible audio recovery action.
- Added opt-in per-tab Chrome capture through an unpacked companion extension.
- Added per-user native messaging registration and stale-helper cleanup.
- Expanded automated coverage for routing, presentation logic, browser setup,
  native host handling, and extension layout calculations.
